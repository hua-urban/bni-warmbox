# BNI 華都更分會・新人保溫箱進度追蹤系統

新會員入會後 8 週保溫箱孵化期的進度追蹤工具。導師協調建檔 → 系統自動生成 8 週檢核表 → 6 位導師勾選完成項目 → 系統算完成度 → 達成畢業條件（4 次培訓＋5 個 121）可標記「出保溫箱」。

- 前台：本 repo（GitHub Pages，僅含 `index.html`，公開可用、免登入）
- 後端：Google Apps Script（`Code.gs`，不進版控，見 vault 筆記）
- 資料：Google Sheet（會員 / 站別設定 / 檢核項目 / 進度 四分頁）

架構沿用分會既有四套系統（GitHub Pages + GAS + Google Sheet），細節與踩坑見 vault `Joan/工作/BNI-華都更分會/`。
